## 3 · The candidate, exactly (C-SCR: «effect screen»)
**Effect (defined at the OUTCOME row of a game act).** The mind keeps the last two GAME eye rows' `(episode, step, sha)`; an eye row whose `(episode, step)` equals the previous one's is a re-published step and is ignored. At an outcome row, `effect` is **known** iff the previous eye row exists and belongs to the SAME episode as the outcome's own eye row; then `effect = 1` if the two `sha` differ, else `0`. Otherwise it is **EXCLUDED/unknown** (the first outcome after an episode boundary, after a snapshot that did not carry the pair, at a life's start): excluded from every window, never counted as 0. It reaches the chooser one outcome late, like reward (the life's lag). **Every live/dead verdict is printed with, per act: outcomes with a KNOWN effect, outcomes EXCLUDED, total (#168).**
**Live set.** For each act, its window = its last **n = 20** outcomes WITH A KNOWN EFFECT. An act with fewer than n such outcomes reads the optimism prior **1.0** (it is LIVE: no act is judged on fewer than twenty outcomes). Otherwise it is LIVE iff the number of changes in the window ≥ **k = 4** (rate ≥ **t = 0.2**), DEAD else.
**Choice.** Exactly TWO act-rng draws every choice: `u = rng.random()`; if `u < 0.1` → `rng.integers(0, 7)` (the landed 10 % uniform branch, unchanged — it keeps every dead act reachable, so the live set can revive); else weights `w_a = 1.0` if LIVE else `0.0` (all dead → all 1.0: uniform), `r = rng.random() × Σw`, the first act whose running sum exceeds `r`.
**Parameters, declared and never swept:** n = 20, optimism = 1.0, t = 0.2, floor 0.1 (landed). **Genome form (Phase 2):** `ACT value effect <n>; optimism <f>; live <t>` (refused by name when `optimism < live`, a window below 1, or any mis-spelling). The journal's `act` row says `policy: "effect-screened"` and its `weights` are the 0/1 weights used.
**Reads only:** the outcome ring and the previous game eye row's `(episode, step, sha)`. **Class A** (a stationary state-blind mixture whose support moves slowly with learned per-act statistics): its own stationary mixture is R-SCR (§4), and the class ceiling 0.4878 applies.
**Scope (stated assumption, tested by T1).** The law is for worlds whose reward does not require an act whose visible effect is RARE in marginal terms. Two ways it fails by construction: with `BABYAI_DONE_ACTIONS` set `done` is required and has effect 0 (the toy refuses that flag); and an act whose effect is CONDITIONAL on a rare state (`toggle` needs a door in front: marginal rate 0.011–0.027 in every door level, probes 3) is judged DEAD although it is the winning act.

### 3.1 How n and t are chosen: the RULE, stated before the selecting walk
The first draft (n = 10, t = 0.3) was flawed (§12). The window and threshold are therefore chosen by this rule, written here BEFORE `orient/screen_select.py` runs:
- **Grid:** n ∈ {10, 15, 20, 30} × t ∈ {0.15, 0.20, 0.25, 0.30}.
- **R1** (a live act is not starved): for a live act with true change rate 0.55, 0.592 and 0.64 in turn (the range the record shows, §1.4), the fraction of CHOICES spent judged DEAD ≤ **2 %** (at the live act's sampling rate 0.3143 and the dead act's 0.0143). *As first written this was a single-act simulation, confirmed on the full 7-act chain within 0.5 percentage point or the law refused; AMENDMENT 1 replaces the instrument by the exact closed form below — thresholds unchanged.*
- **R2** (a no-op is not kept alive): a no-op with true rate **0.12** (above every observed no-op rate, max 0.090) is judged LIVE ≤ **5 %** of choices (the same level as M4(a)'s bar).
- **R3** (the reading window is clean): the startup's p99 (the act index by which every act has ≥ n known outcomes, full chain) ≤ **240** (M3/M4 read acts 241–960).
- **Selection:** the first configuration, ordered by n ascending then |t − 0.2| ascending, that meets R1–R3. If none does, THIS LAW IS REFUSED BY ITS OWN ARITHMETIC and v3 follows.
- **Prediction before the walk (from the exploratory grid, `orient/screen_markov.txt`, committed):** the rule selects **(n = 20, t = 0.2)** and no other of the 16 configurations. The exploratory walk is disclosed as the source of that prediction; the SELECTING walk re-runs the grid on fresh seeds and applies the rule mechanically.
- **AMENDMENT 1 (before signature): the instrument of R1/R2 is EXACT, not simulated.** The Monte Carlo selecting walk (`orient/screen_select.{py,txt,json}`, seed base 20261004, committed with its output) selected **(15, 0.15)** and then FAILED its own confirmation: at forward 0.592 the single-act chain read 1.34 % dead and the full chain 0.69 % (0.65 pp apart, limit 0.5 pp). That is an INSTRUMENT defect (RULES §2), so: thresholds, grid and order are untouched; R1 and R2 are computed in closed form. At the instants an act is sampled its window holds its last n outcomes, which are iid Bernoulli(p) whatever the sampling times, so the window state seen at a sample is the product measure and P(dead) = P_d = P(Bin(n, p) < k) per sample; after a sample the act waits a geometric number of choices (mean 1/λ) for the next one, λ_a = 0.3143 live, λ_d = 0.0143 dead; renewal-reward: **the fraction of CHOICES spent dead = (P_d/λ_d) / (P_d/λ_d + (1 − P_d)/λ_a)** (a no-op wrongly live uses λ_a' = 0.2393, four live acts). The simulation is kept as a CROSS-CHECK within 3 standard errors of 8 replicates, and as THE PLANT: v1's reasoning (the per-evaluation share read as a time fraction) must be CAUGHT as wrong. R3 (the startup's p99) stays a simulation, far from its limit on both sides.
