## 1 · The question, what a pass settles, what it cannot

**The question.** Can `produce_believed` enumerate its candidates length-ordered under a declared budget — so that the winner it returns on every canvas any closed record carries is BIT-IDENTICAL to today's, and a canvas whose enumeration would exceed the budget gets a DECLARED overflow form instead of an unbounded freeze?

**A pass settles:** (i) on the fixture corpus the new enumeration's every output field equals the old enumeration's, ties and «none» and one-alone included; (ii) the full-tape replay of brain-long-2 under the new code is byte-identical to the old code's journal, and brain-full-20261102's replay journal matches its recorded sha256 — the two negative-controlled gates; (iii) the overflow path fires exactly in its declared form when forced, inside a measured time bound; (iv) a rich-talking world can no longer freeze a mouth for hours — the per-canvas worst case is the budget, by construction.

**It cannot settle (each said now):** that the budget never binds on the MENTOR stream (its bind rate is W2's own reading R-BIND, no bar here — W2's marks judge what it does to the bench's populations); that a W2 LIFE should launch (the next law's question, which must price the budget path live); any change to WHAT the mouth believes (the learner, the roads, the bands are untouched); the mentor's type-shattering itself (a hearing-design question, the W2 life's law's, never this law's).

## 2 · The build (one file of organism code, one declared constant, additive diagnostics)

`brain/scene/learners.py: produce_believed` — and nothing else of the organism (the builder's pin gate: `git diff --stat` over everything except {`brain/scene/learners.py`, `tests/brain/scene/test_learners_mouth_cap.py`, `docs/`} is EMPTY).

1. **Length-ordered generation.** Candidates are generated per length class k = 1 … len(say) (`itertools.combinations` over `say` — never a materialized `2^N` list: at the ON tape's mature-26 the old list alone would be tens of GB). Per class: the believed-unique filter, then the read-backs; **stop after the first class holding ≥ 1 accepted** — the winner is that class's best-ranked accepted. Identical to today's winner BY the rank's own first key (length): every accepted of a shorter class would have won, so no accepted of a longer class is ever needed. Within a class every candidate is still evaluated (the margin tie-break needs them all).
2. **The declared budget.** `MOUTH_BUDGET = 4096` — module constant; counts candidates CONSIDERED (each uniqueness evaluation = 1; the read-backs are a subset). The value: ≈ 585 × the closed record's measured maximum (7, item 2) and a measured worst canvas of 4,096 × 4.7 ms ≈ 19.3 s (item 5). When the budget is spent mid-class with no accepted found in any completed class — **the only shape it can take** (a completed class with an accepted stops the enumeration first) — the result is the DECLARED OVERFLOW FORM: `spoken None, reason "the mouth's budget"`, with `n_considered`, `n_say` and the budget printed in the row. This reason string is NEW and must never appear on the closed record (M-TAPE's gates prove it does not).
3. **Additive diagnostics only.** `n_candidates` stays EXACT, computed arithmetically (2^len(say) − 1 — never enumerated); `n_unique` / `n_accepted` on the early-stopped or budget-cut path report the CONSIDERED prefix and the row carries `"exhaustive": false` — these fields are not journaled (item 4); the journaled `say` dict's keys are pinned by G-CALLERS.
4. **A test-only parameter.** `produce_believed(road, X, target, rng_factory, budget=MOUTH_BUDGET)`: the parameter exists so the budget path is exercisable in tests at 64; **every organism call site uses the default** (G-CALLERS' grep gate). `genome/brain.py` is untouched.
