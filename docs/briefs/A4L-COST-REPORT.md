## 2 · Task 1 — the construction, chosen by the bars (measured, `scratch/task0/witness_probe.log`, the 10:54 snapshot copy, load 3.9)
| on 6,896 × 753 born (10,940 masked of 5.19 M) | ms a call |
|---|---|
| the dense `state_hash()` | **144.2** (the live block 119.5 · the logs' json 16.2 · cells 6.9 · own_band 0.6 · alive+misfires 0.05) |
| (a) a scan of `mask[:n_s, :n_w]` + gather + sha256 | **24.8** (the scan alone 24.0 — quadratic, over C2's 10 ms witness bar already) |
| (b) a per-sight-row digest | 7.4 µs a row; a word's DELTA column update dirties 11 (median) … 54 (max) rows |
| **the chosen form: a gather at the MAINTAINED coordinate set + sha256** | **0.87** (1.94 with everything else, steady, C4) |

**Chosen: (b), in its cheapest safe form.** The ONE incremental piece for the block is the SET of masked coordinates (sorted int64 keys s << 32 | t). It changes only where the MASK changes — `_hebb`, `_prune`, `_merge`, each of which marks the sight rows it touched; the set is re-read for those rows only at the next digest (a full scan when more than an eighth of the rows are marked). **Every W/strikes/mask VALUE is gathered fresh on every call**, so a VALUE write the witness is never told about (DELTA's column updates, SCALE, the clip) is still seen — per-row VALUE digests (the brief's literal (b)) would need five writers to mark instead of three, and the rows DELTA's column update dirties (up to 54 a word) to be recomputed in Python. The cells (written once, at birth) and the four logs (only ever appended) are running sha256s — the logs' stream is `json.dumps(log)[1:-1]`, the entries joined by json's own ", ", so it is the same however the appends were chunked. alive/misfires/own_band/counters/t/budget are hashed whole each call (small). A domain tag leads, so a sparse digest never equals a dense one. **Lossless by the invariant** — W ≠ 0 (bit-level) ⇒ mask ≠ 0 and strikes ≠ 0 ⇒ mask ≠ 0 inside the live block, and the padding all zero: 0 violations on the snapshot copy (a test) and at the hour-1 fixture's final state (a test, and all five C1 replays). **Undeclared: `row_hash()` is `state_hash()`** (gate 2's pin unmoved: gate_g4 PASS). **The dense digest stays in every snapshot's meta** (`save` untouched) and `load`'s verification chain is unchanged.
