## Decisions taken in the reader (for the seat's PREREG addendum — none of these is a bar change by the reader; each is a reading rule)

## (b) The racy close — creature/body.py:stop's 5 s join, made precise (read from the code; nothing in the body touched)

The stop road, in order (creature/body.py:424-448 `stop`; main:770-780 — SIGTERM sets `stop_requested`, the main thread calls `body.stop()`; the unit creature-g5@.service has TimeoutStopSec=120, so the whole of stop() has 120 s before SIGKILL):
1. `stop_event.set()`; every sense thread `.stop()` then `.join(5.0)`; the senses stop publishing → the tape's head is fixed at H. The status thread's `wait` returns at once on the event: it writes STATUS once more (≈ t+0) and exits.
2. `_mind_thread.join(timeout=5.0)`. The mind thread is in `_mind_loop`: `row = q.get(0.5)` → `_consume(row)`; it checks `stop_event` only BETWEEN rows. It ends within 5 s iff the row in flight (call it N; the mind COMPLETED rows ≤ N−1) finishes within 5 s. Nothing reads the queue after that: rows N+1..H stay unconsumed [Certain].
3. `mind.close()` on the MAIN thread — whether or not the mind thread ended (`join` returns None on timeout; the code never checks `is_alive()`) [Certain]. close() (creature/mind.py:2726-2739): (i) if `_think_pending` is not None → `_think_apply_pending({"at": _cur_at, "seq": _cur_seq})`: waits for the think future, APPLIES its plan into the organism and writes a `think` journal row (with `launched_at`) at `_cur_seq`; `_cur_at/_cur_seq` are set at the TOP of `_consume_eye` (mind.py:1163-1164), so if N is an eye row in flight they are N's, else the last eye row before N; (ii) `_think_executor.shutdown(wait=True)`; (iii) `snapshot()`: organism.npz/json + ledger.json (`last_seq` = `self.last_seq`, which consume() sets only at its END, mind.py:640 — so N−1 while N is in flight) + the episode rings.
4. `_write_status(_build_status())`: `last_seq` = mind.last_seq (N−1 while N is in flight), `mind_backlog_rows` = q.qsize() = H − N (row N was dequeued) [Certain].
5. `_journal_event({"event": "stop"})` (at = wall time).
