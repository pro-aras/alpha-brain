## THE CODE ANSWERS

### Is there any n-gram model, transformer, embedding table, attention layer or gradient-trained network inside the creature's mind?
**No.** A grep for `n-?gram|transformer|attention|embedding|softmax|backward|backprop|autograd|torch|gradient|nn\.Module|optimizer|\.grad` over `creature/` and `genome/` returns hits in exactly **one** file plus the tower trainer:

- **`genome/traits.py`** — the only gradient machinery in the tree: `traits.py:31` ("Embeddings z1 = H @ x_s … each L2-normalised"), `traits.py:33` (InfoNCE softmax cross-entropy), `traits.py:138 _infonce_grad` ("One gradient step of InfoNCE … Standard softmax-cross-entropy-through-L2-normalise backprop, worked out by hand — **no autodiff library in this estate's numpy-only** …"), `traits.py:98` (`learn()` updates `self.H` in place). **It is OFF**: `TRAITS` is `#OFF` in `G5.genome`, `creature/genes.py:108` records `"TRAITS": None` (no interpreter), and `mind.py:145 genes.unwired()` would **refuse the organism to start** if the line were switched on. There is a live call site at `mind.py:520-521` that the registry says should not exist — the registry and the call site disagree, and only the OFF flag keeps that from mattering. (Note also: it calls `Traits.learn(...)` on the *class*, while `traits.py:98` is an instance method.)
- **`genome/train_eye.py`** — the trainer that *produced* the sealed tower (`train_eye.py:59` "a tower of ARCH's layers + a softmax head"; `train_eye.py:3` a gradcheck). It is a build tool, not part of the life; nothing in `creature/` imports it.

No n-gram model, no transformer, no attention layer, no embedding table, and no optimizer anywhere in the running mind. There is no `torch`, no `tensorflow`, no autodiff — the whole organism is numpy arrays and explicit loops.

**The sealed eye tower (a frozen conv net used as a fixed front).**
- Loaded at **`genome/eye.py:tower()`** (module-level cache `_CACHE`), which builds **`genome/eye.py:EyeTower.__init__`** from `SEAL.json` + `tower.bin` under `DEFAULT_DIR = /data/dev/alpha3/judge/eye-tower-g2` or the genome's own `judge/` (`eye.py:37-38`).
- Reached from the retina at **`genome/machinery.py:432-434`** (dimension) and **`machinery.py:469-472`** (forward), triggered by the genome's `RETINA … tower:eye-tower-g2 …` step.
- **It is frozen, three ways over:** `eye.py:52-54` refuses any `tower.bin` whose sha-256 is not the seal's; `eye.py:55-59` refuses any array whose shape is not the seal's; and `eye.py:21-22` states and enforces that the classifier **HEAD (`Wh`, `bh`) is deliberately not used** — *"the organism grows its own words over the features … Nothing here is trained, tuned or re-derived."* The forward is `conv 8@5 → ReLU → maxpool2 → conv 7@3 → ReLU → meanpool4 → 112 features` (`eye.py:19-20`). No weight in it changes during a life.

### What are "synapses"?
Two structures, both in `genome/machinery.py`:
- **Cells (the units):** `Area.cells` — `machinery.py:515` `np.zeros((nmax, dim), float64)`, with `Area.alive` (`machinery.py:516`) and `Area.misfires` (`machinery.py:517`). Two areas: `sight` (dim 112, or 144 with colour) and `words` (dim 8×27), built at `machinery.py:564` and `machinery.py:565`. A cell is a **unit-length prototype vector**, born holding the input that no existing cell resonated with (`machinery.py:645-646`).
- **Edges (the synapses):** one shared matrix **`Organism.W`** — `machinery.py:566` `np.zeros((nmax, nmax), float64)`, indexed `[sight cell, word cell]` — with **`Organism.mask`** (`machinery.py:567`, `uint8`: does this edge exist at all) and **`Organism.strikes`** (`machinery.py:568`, `uint8`: how many PRUNE chances it has used). An edge is born at `w = lr` (`machinery.py:713`) and every birth/prune is logged by cell id with no label (`machinery.py:583-584`).

### What plays the role of dopamine / modulation?
**PREDICT's error, scaling DELTA's learning rate for one moment.** The chain, end to end:
1. `creature/mind.py:395` — `err = self.predictor.error(g["feats"][0], word=word, xw=xw, episodes=self.episodes)`
2. `creature/mind.py:396` — `lr_scale = self.predictor.modulate(1.0)`
3. `genome/predict.py:236-242 modulate()` — `scale = clip(0.5 + 3.0*e, lo, hi)`, returning `lr * scale`
4. `creature/mind.py:441` — `S, T = self.org.moment(x, xw, lr_scale=lr_scale)`
5. `genome/machinery.py:686` — `self._delta(S, T, lr=self.g.lr * lr_scale)`

So a surprising moment learns up to **2×** faster and an expected one as little as **0.5×**. The error itself is the **comparator** arm (`predict.py:209 _error_comparator`): `err = 1.0` when the winning sight cell's *established* answer is not the word actually heard — a genuine expectation violation, not a novelty score. The same `err` is also written onto the episode (`mind.py:447 surprise=err`) and is what SLEEP ranks replay by (`sleep.py`, via `Episodes.most_surprising`). One signal, three jobs — exactly the dopamine shape.
*Caveat on the wiring:* the genome's declared bounds `0.5..2.0` are parsed into `declared["PREDICT"]["delta_lo"/"delta_hi"]` (`machinery.py:275`) and **never passed** — `mind.py:187` and `mind.py:982` construct `Predictor(org, arm=…)` only, and `predict.py:112` defaults `lo=0.5, hi=2.0`. The numbers agree by coincidence, not by reading.

### Is there any plasticity rule beyond HEBB / DELTA / PRUNE / MERGE?
**Yes — three more, all in `genome/machinery.py`:**
1. **`_birth` — structural plasticity** (`machinery.py:622-652`). New units are created at runtime, under a per-arrival BUDGET (`:642`), a hard NMAX (`:637`), and CYCLE's soft ceiling at 0.9·NMAX (`:629-644`). This is the creature's principal form of learning: 1466 cells in 2 hours.
2. **`_misfire` — error-driven structural plasticity** (`machinery.py:742-765`). A cell whose strongest edge points away from this moment's winners strikes; after `BIRTH error misfires 3` a new cell is born beside it holding the current input — unless it would be born redundant (within THETA_M), which is refused and counted (`:757-759`).
3. **`_scale` — synaptic scaling / homeostasis** (`machinery.py:823-835`). Every `SCALE every 1000 moments`, each cell's edge vector is normalised **down** to unit norm when it exceeds it — *"never up, never removed"*. This is the estate's own SHY-compatible down-selection (design §2 finding 15). Note it is *not* what makes `removed_for_disuse` read 0 — that counter (`machinery.py:578`) has no incrementer at all; there is simply no disuse rule in the tree.

Plus one that is **built but switched off**: `TRAITS` (`genome/traits.py`), an InfoNCE-trained projection `H` that would sit between the frozen tower and the cosine (`machinery.py:531-551 Area.cos` has the branch for it). It is the only gradient rule in the tree and it is OFF with a measured reason.

And one **cadence** rule that is not plasticity but changes what plasticity sees: **SLEEP** (`genome/sleep.py:sleep`) replays the 200 most surprising episodes back through `Organism.moment()` as ordinary moments, so all five rules above fire again on them; **CYCLE** (`sleep.py:55 cycle`) then runs a merge pass that lowers the alive count and reopens the birth gate with fresh ids.
