- **Source:** Graziano's ethological map (M2: acts, not muscles); Lederman & Klatzky's EPs (M9: a fixed set, each matched to what is wanted); BLUEPRINT §A1.2's own six (*adopt · file · fetch · run · ask · abstain*) — **this line is that list, minus the two that are not acts on the world**; his ROS sentence (*"a motor-control node"* alongside the camera and mic nodes).
- **The test that could refuse it:** over one life, the **act census** — one count per verb, never a total (#165). **Refuses the line if:** one verb takes ≥ 95 % of acts, or any verb takes 0 — in the first case the set is a single act with decoration, in the second the set is smaller than it claims. **Ceiling before the bar:** with `say` and `run` OFF and the web door unbuilt, only **three** of six verbs can fire today, so the bar is computed over the three that can — printed as `3 of 6 reachable` beside every reading (#228 a: never place a plant where the mechanism cannot fire).
- **Twin:** `--blind act` — the same tape with the ledger not written. Every existing mark must read **byte-identical** to the live life, or the ledger is changing decisions rather than recording them.
- **Cost:** ≈ 0 (one row per THINK pass ≈ 0.02 rows/s against the tape's 0.219).

### G-MOT-2 — the outcome of an act becomes an experience

```
OUTCOME  act to episode; error grades it; ranks replay    # new vocabulary
```

*This is the load-bearing line of the whole document.* An act's result is written as a FAST episode keyed on the act, with the residual (`expected` vs `got`) as its surprise — which means SLEEP already replays surprising acts into SLOW, and PREDICT's modulator already scales learning by them. **No new learning machinery is required; the existing modulator is pointed at a new source.**

- **Source:** F1 (*"an error signal needs a channel from outside: the world, a second independent source, **an outcome**"*); GAP-MAP item 7 (*"the exam sitter as HIS duty with an outcome he perceives: **this is the reward signal**"*); §1.4's whole column (every motor learning result in biology is an outcome reaching the learner); G4-DESIGN row 3b (*"the error is the ONE modulator … it **grades the act**"* — the design already said `act`, and nothing acts).
- **The test that could refuse it:** a **predictable** act and an **unpredictable** one in the same stream. The predictable act's residual must fall with repetition; the unpredictable act's must not. **This is E21's shape and E28's warning together**: E21's magnitude-only twin read **59.17 %** against the model's 100 %, so the residual must be shown to come from the **prediction** and not from how much changed. **Refuses the line if:** the residual is as large on the predictable act as on the unpredictable one after N repetitions — then it is reading change magnitude, and the line is not built on it.
- **Twin:** `--blind outcome` — acts happen, no episode is written. Retention and the duty mix must be unchanged, or something other than the outcome moved them.
- **Ceiling:** E21's degraded table is the ceiling curve and it should be printed beside the bar: a forward model corrupted 40 % still separated at **93.33 %**, and only at 80 % corruption did it fall to **61.67 %**. A creature's first forward model will be far worse than 40 %-corrupted-scripted.
- **Plant:** an act whose outcome is **known to the world-maker and unknown to the mind** — the world writes truth outside the organism already (`root/truth/*.json`), which is the estate's existing shape for exactly this.
- **Cost:** one episode per act. Free.

### G-MOT-3 — his own sitting comes back to him

```
SIT      exam every 2000 canvases; the score returns as a sense   # extends EXAM (new vocabulary)
```

*The cheapest closed loop available today, and it is one sense thread.* He already sits the exam and the file is already written; nothing reads it. A `sense` thread publishes `run/exam/<stamp>.json`'s score onto the tape as a row; the mind consumes it like any other row and writes an episode.

- **Source:** GAP-MAP §2 item 7 verbatim; HUMAN-MECHANISMS §3.6 (*"the exam measures an organ, it does not create one"* — which is the caution, not the objection); F1.
- **Why it is safe by construction:** the one-writer law is preserved — `exam.py` already loads a **private** Organism from disk and never touches the mind's objects; the new thread only *publishes*, exactly as the folder door does. Replay is preserved because the score arrives as a tape row.
- **The test that could refuse it:** the exam's own score must **move** across a life (life 2's slid .995 → .952 after window 2). **Refuses the line if:** the score is constant, because a constant signal teaches nothing — and it must be checked **before** the wiring, on life 2's closed record, which is on disk.
- **Twin:** `--blind sit` — the exam runs, the score is not published.
- **The trap to avoid, and it has already bitten once here:** `exam.py` carries its own scar — *"the voice's pointer LAST.json sorted AFTER every stamped file ('L' > '2'), so the event row read the pointer and journaled q1 null while the stamped file held Q1 .991"* (#168's class). **The publisher must select the file the same way `exam.py` now does** (digit-prefixed, sorted), never by a pointer.
- **Cost:** one row per 2,000 canvases ≈ nothing.

### G-MOT-4 — the first HANDS act

```
HANDS    jail alpha3/hands/jail_run shelf world/programs cpu 10 mem 512 wall 20   # extends the parsed HANDS (new vocabulary beyond `jail <path>`)
```

*Rung 1: he CHOOSES a program from a small shelf and runs it; its output is an episode.* Not *writes* — §0.5. The shelf is a directory of small programs each with a known output; choosing which to run is an act in the `ACT` set; the output is the outcome.

- **Source:** G4-DESIGN row 6; his own *"ground it later through the system's own **sensors and actions**"*; M8 (the crow: an invariant procedure applied to chosen material, before composition); `src/hands.hpp`'s own limits as the defaults.
- **The three things that must be true before it is switched on, each a line of code, not a judgement:**
  1. **The output is decoded with `errors="replace"`, never strictly.** #230 in one sentence: a 400-byte head cut through a multi-byte glyph, a strict serializer, and **90 core dumps in 20 minutes**. The C++ estate's fix is `textsafe.hpp`; the creature is Python and has none. `src/hands.cpp:61-64` truncates at `kCapBytes` **by bytes** — the identical trap, still open on this road.
  2. **The cursor advances only after the row it names is written** (#230's second half: a persisted cursor turned a data crash into a crash LOOP). The folder door already does this correctly and says so; HANDS must copy it.
  3. **Each act gets a fresh scratch** (#212: a measurement run gets a fresh root), and `ro_root` is the shelf directory — **never the creature's own tree**.
- **The test that could refuse it, with its controls:**
  - **positive control:** a program whose output the mind can predict exactly (it prints a constant) → residual **0**, the act is recognised as self-caused. This is E21's shape and it is the only cell where the ceiling is known.
  - **negative control (#175: the control must control something):** a program whose output the mind **cannot** predict (it reads a file the world-maker wrote this window) → residual > 0. **If the residual is small on both, the forward model is decoration** — and E28 already measured that outcome once, at AUC 0.6656.
  - **the crash control, and it is the one that must run first:** #230's own program — the one whose glyph aborted the organism 90 times — run through this road. It must produce **a tape row containing U+FFFD and an exit code**, and the mind's counters must keep moving. A `hands_selftest.cpp` regression for exactly this exists in the C++ tree (`src/hands_selftest.cpp`, written 2026-09-19 13:59 for that crash loop); the Python road needs its twin.
  - **the fence control:** a program calling `socket.socket()` must produce a row reading *Permission denied*, not an error in the creature. Proved once by hand on 2026-09-16; it must be a test.
  - **Refuses the line if:** any control crashes the mind, or the positive control's residual is not 0.
- **Twin:** `--blind hands` — the act is chosen and journaled, the jail is not called, the outcome row is absent.
- **The replay problem, named not solved:** a jail run is **not** reproducible (pids, clocks, `random`, scheduling). The act's **intent** must be a pure function of (genome, seed, tape), and the act's **outcome** must be a recorded tape row that replay reads rather than re-runs. **This is a body change, not a gene value**, and it is §5 Q1.
- **Cost, measured, not assumed (§0.4):** **p50 1,051 ms · p90 1,125 ms · p99 11,010 ms · max 11,024 ms over 305 real runs**, 0 errors, 0 fallbacks, bounded by contract at ≤ 20 s wall / ≤ 10 CPU-s / ≤ 512 MB. **Budget the tail, not the median:** 302 of 4,135 ledger rows record a `max` at or above 20,000 ms — the deadline firing. At one act per THINK pass (every 10 canvases = every 50 s of drawn world) a one-second act is invisible and a deadline-hitting act is not, so **an act that can hit the wall must not run on the mind's thread**.

Everything else in §1 carries `[secondary: URL]`, which on this document means **a search result that named the primary and quoted its number; the primary itself was not opened.** SAGE returned HTTP 403 on Adolph 2012 and the Pitzer PDF returned metadata only, so **2,368 steps / 17 falls is quoted from two independent summaries of the abstract, not from the paper.** Before any of these numbers goes into a growth line, its primary is read at an open mirror (#194, #196).
2. **That the Smith 2006 parameters are labelled correctly above.** The fetch returned the fast/slow labels apparently transposed against the paper's own description, so the two processes are stated **by property** (retention vs responsiveness), which is unambiguous, and the label question is flagged rather than guessed.
3. **That E21's 100 % says anything about this creature.** E21's own first line refuses that reading, and `BODY-SENSES.md` §5 already records why: for this creature, self/world *attribution* is partly free because the tape stamps `meta.source` on every row. What is not free is **content** — did my act produce what I expected — and that is what §4's `OUTCOME` is for.
4. **That the creature needs hands.** Its world is drawn shapes on a 5-second cadence. An arm with nothing to grip is an organ that will pass its own tests and change no decision — the estate's oldest failure shape, and the reason §4's `WORLD` line and §5 Q3 exist rather than an assumption.
5. **That choosing from a shelf is a real act.** It is the smallest thing that can be called one, and §0.5 argues it is the right first rung; but a shelf the seat wrote is the seat's vocabulary, not his, and F10 is the standing warning that recombination over a fixed alphabet is not invention.
6. **That the octopus row transfers.** The register graded it **EARLY** on a safety argument that still holds for a general arm. The jail narrows it to *reversible and cheap*, which is the register's own escape hatch — but narrowing an objection is not answering it.
7. **That I measured the jail myself.** I did not run it. The per-run figures in §0.4 are **read from Alpha 3's own road ledger** (305 calls, p50 1,051 ms, p99 11,010 ms), which is a record of that organism's runs on this box, not a benchmark taken for this document; the E14/E21 figures are the desk harness's and are labelled as such. *An earlier draft of this document said no per-run cost existed anywhere — it did, in `run/roads.jsonl`, and the claim was corrected before the document was handed back. It is #168's shape: a negative from a search that could not have returned the thing.*
8. **That the act vocabulary in §4 is complete or right.** Six verbs were chosen because BLUEPRINT §A1.2 already names them and because three of them exist as roads today. Q2 puts the set to him.

## The three questions only Ahmad can answer

**Q1 — When the creature acts, what does REPLAY mean?**
This is the one that is not a preference. Today the mind is a pure function of (genome, SEED, tape), and `creature replay` reproduces its journal byte for byte — the one check this creature has never failed. A jail run is **not** reproducible: pids, clocks and `random` differ every time. Two roads, and they are different creatures:
(a) **the act's outcome is a recorded tape row, and replay reads the recording** — replay stays byte-identical, the tape grows, and a replayed life re-lives an act it did not re-take;
(b) **the act is re-run at replay time**, and byte-identity is replaced by something weaker (the *intent* replays identically, the *outcome* need not).
**(a) is the recommendation** — it preserves the property, it is what the folder door already does with its payloads, and #230's lesson is that anything from outside enters as recorded bytes. But (a) means the creature can never *re-do* an act, which is a real loss for a system whose whole advantage over biology is that it can. *Which is it?*

**Q2 — What is in the act set?**
§4 proposes six — `glance · open · fetch · run · say · ask` — from BLUEPRINT §A1.2's own list. The choice is not neutral: an act set is a vocabulary, and a vocabulary the seat wrote is the seat's, not his (F10). Three variants:
(a) **the six above** — every road that exists or is planned, three of them reachable today;
(b) **only what is reachable now** — `glance · open · ask` — with `run` and `say` added when their organs switch on, so the census can never read `0 of 6`;
(c) **two** — `open` and `run` — the smallest set where an act can have a consequence at all.
*(b) is the recommendation*, because a verb that cannot fire poisons every mark computed over the set. *Which?*

**Q3 — Where does the consequence come from?**
An act needs a world that answers, and today's world is a seeded schedule that answers nothing. Four roads, and they are not the same creature:
(a) **the jail** — he runs a program and reads what it printed. Real, built, fenced, and the consequence is exactly as rich as the shelf;
(b) **his folder** — what he opens changes what he is shown next. Cheapest, fully under his control, and the smallest thing that is honestly a consequence;
(c) **the exam** — his own sitting, with the score returning as a sense (§4's `SIT`). **One sense thread**, the file already written, and GAP-MAP called it *"the reward signal"* two days ago;
(d) **the open web** — the richest and the only one that is genuinely outside him, and the one gated behind the five-adversary suite (BLUEPRINT §A1.4) that has never been run.
**(c) then (b) then (a) is the recommendation** — in that order, because (c) costs one thread and closes the loop F1 names, (b) makes his own acts matter inside a world that is already replayable, and (a) is the first act on something that is not himself. *(d) is his call alone and this document does not propose it.*
