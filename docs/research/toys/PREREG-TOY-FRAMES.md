## 1 · The compressor (fixed before any run; every rule is graded by the SAME code)
- **Data:** moments (utterances) in seq order; a moment's words in the order heard. **Split:** the first 60 % of the moments are TRAIN, the last 40 % HELD-OUT (KW-1's fraction), by seq.
- **A frame** is an ORDERED pair `(a, b)` of words. **The parse:** inside a moment, left to right, `(a, b)` ∈ F at the next two words → one FRAME token, else one WORD token; the parse never crosses a moment (a frame lives inside an utterance, as SENTENCE's own domain). A single-word moment is a unigram token.
- **The token code, SELF-DELIMITING [arch 12:0x, option END]:** every moment's token sequence is followed by ONE END token, so the code pays for the length of each moment and is a code of the utterance sequence itself — a decoder is handed no boundaries. The token's probability is its count in the TRAIN parse under F (END counted once per train moment), add-one smoothed over the token inventory (words ∪ frames ∪ UNK ∪ END): `p(t) = (c_t + 1) / (N + K)`, `N` = the train tokens INCLUDING the END tokens, `K` = inventory size; a held-out word never seen in train is UNK. **Why END, and not the boundaries for free (the architect offered both):** a code handed the boundaries is handed each moment's TOKEN count, and under a frame set that count depends on whether a frame fired — up to log₂ 3 = 1.585 bits an utterance on SCENE (three possible counts), not the 1.5 bits of the word length. So «6.0774 − 1.5 = 4.5774» bounds only the F = ∅ code; with END the code is a proper code of the utterance, and the generator's own probability is the exact bound (§3).
- **The model cost** of F: `L(F) = |F| · 2 · log₂ V` bits (a frame is spelled by its two words), V the train vocabulary.
- **The gain:** `G(F) = bits(held-out | ∅) − bits(held-out | F) − L(F)` — how many bits F saves on text it never saw, net of its own description; `G(∅) = 0`; per held-out word `g = G / N_held`. A frame set that costs more than it saves has G < 0.

## 2 · The three rules (the candidates; each returns a set F of ordered pairs from the TRAIN part only)
- **(a) WEB** — `genome.web.Web`: rule **H** (once) and rule **S** with `B = 2V` (seeds 1–10, KW-1's), the train words fed in order; `consolidated()` returns unordered edges; each becomes the ONE ordered adjacent pair with the larger within-moment train count (ties: alphabetical); an edge with NO within-moment adjacent train occurrence is dropped and counted («no adjacent occurrence»).
- **(b) SENTENCE** — `genome.sentence.find_frames` over the train moments (a stand-in store exposing `get(i)` → `{"words_in_instant": …, "id": …}`, `n_written`, `cap`), `min_count` 5, `factor` 2.0, as the cells ran it.
- **(c) MDL-GREEDY** — candidates: every within-moment adjacent train bigram with count ≥ 2; greedily add the frame with the largest TRAIN gain `Δ = bits(train | F) − bits(train | F ∪ {f}) − 2 log₂ V` (the exact count-based change, the parse re-made after each addition, ties by the pair's name), until no candidate has Δ > 0.

## 3 · The streams, the nulls, the controls
- **ALPHA4** (the real stream): alpha4-1's ear rows, all five sources, seq order — 84,275 moments, 112,489 words. **SCENE** (the control with a known generator): brain-full's 10,000 scene moments.
- **NULL-1, THE NULL OF THE GAIN BAR, a distribution of 100 draws (≥ 20, #244 (2)):** for a rule's set F of k frames, a DEALT set F′ of k pairs: each frame `(a, b)` is replaced by `(a′, b′)` with `a′` drawn uniformly from the words whose train count is in the same log₂ bin (width 0.5) as `a`'s, `b′` likewise, `(a′, b′) ∉ F`, `(a′, b′) ≠ (a, b)`. Same size, same frequency profile, same model cost; only the pairing is chance. The null statistic is `G(F′)`; q95 = its 95th percentile. Draws from `default_rng([20261103, rule_tag, seed])`. It ablates the PAIRING; it does not ablate adjacency — a chance word pair is almost never adjacent inside a moment, so its frame never fires and `G(F′) ≈ −L(F′)`, and any rule whose frames are adjacent clears it (the architect's point, which is why NULL-2 exists).
- **NULL-2, THE ABLATED SELECTION CRITERION (a READING; no bar moves) [arch 12:0x]:** does a rule's CRITERION (SENTENCE's lift, the web's consolidation, MDL's gain) pick better pairs than «a random ADJACENT pair of the same count»? For a rule's set F of k frames, a DEALT set F″ of k pairs drawn from the TRAIN's within-moment ADJACENT bigrams (every distinct ordered pair seen adjacent inside a train moment): each frame `f` is replaced by a bigram `f″` whose own train adjacent count is in the same log₂ bin (width 0.5) as `f`'s own, `f″ ∉ F`, `f″ ≠ f`, the k replacements distinct. A frame with adjacent count 0 (a pair never adjacent, which SENTENCE and the web may keep) is matched into the lowest bin (count 1). A bin without enough candidates falls back to the nearest non-empty bin; the number of fallbacks is counted and printed per rule. 100 draws from `default_rng([20261103, rule_tag, seed, 2])`; the statistic `G(F″)`, its mean / sd / q95. Printed per rule beside the GAIN bar: `G(F)`, NULL-2's mean / sd / q95 and z, and **CRITERION-MATTERS** = `G(F) > q95(NULL-2)` and `G(F) > 0` (WEB-S: the seeds passing, of ten). **PLANT-BEATS-NULL-2 (a gate on the reading, §4).**
- **PLANT (a positive control; every rule must FIND it):** a copy of the stream in which, after every 100th moment (ALPHA4) / every 10th (SCENE), a NEW moment `["zzq", "xxv"]` is inserted — two tokens in no vocabulary. Each rule must keep `("zzq", "xxv")`, and its `G` must be positive.
- **SHUFFLE (the instrument finds nothing in structure-free data, KW-1's K7):** train and held-out words each permuted among their own positions (the moments' sizes kept), seed 1.
- **THE CEILING (SCENE only; a GATE) [arch 12:0x, replaced — the first text set the bound from 6.0774 bits for a code that was handed the boundaries, so it was not a ceiling].** The generator's own probability of each utterance, from its constants (`brain/scene/world.py`: a template uniform over T1–T4; the referent's (shape, colour) uniform over the 24 ALLOWED pairs; its size uniform over big / small): `P_gen(«⟨shape⟩») = ¼ · n_s/24` (n_s = the allowed pairs with that shape: 4 / 3 / 4 / 4 / 5 / 4), `P_gen(«⟨colour⟩ ⟨shape⟩») = ¼ · [pair allowed]/24`, `P_gen(«⟨size⟩ ⟨shape⟩») = ¼ · ½ · n_s/24`, `P_gen(«⟨size⟩ ⟨colour⟩ ⟨shape⟩») = ¼ · ½ · [pair allowed]/24`. It is a code of the utterance sequence, and any other code Q (the END code is one) beats it by `b` bits only with probability ≤ 2^−b (the likelihood-ratio bound: `P_gen(Q/P_gen ≥ 2^b) ≤ 2^−b`; the held-out part is independent of the train part). So `G_max = bits(held-out | ∅) − Σ_i −log₂ P_gen(u_i)` over the held-out utterances `u_i`; its expectation is `bits(held-out | ∅) − 6.0774 · N_utt` (6.0774 = 2 + ¼ H(shape) + ¼ log₂ 24 + ¼ (1 + H(shape)) + ¼ (1 + log₂ 24), H(shape) = 2.5698). **GATE-CEIL:** on the plain SCENE stream, every rule's `G` and `G(F_oracle)` must be ≤ `G_max + 20` bits (a false stop has probability ≤ 2⁻²⁰ a check); a violation is an INSTRUMENT ERROR — the run is void and STOPS until the cause is named in an amendment. Printed beside it: the expected form `bits(∅) − 6.0774 · N_utt`, and `H(utterance | length) = 6.0774 − H(length) = 6.0774 − 1.5 = 4.5774` bits an utterance (H(template | length) = 0.5: only length 2 leaves T2 and T3 open) — the bound for a code that is HANDED the lengths; this code is not (END), so that figure is a reference, never a gate. A held-out SCENE utterance the four templates cannot produce (none expected: the one «dax» scene, index 2,699, lies in the TRAIN part) is a STOP of the same kind. The gate is LOOSE (a unigram code's overhead over the generator is whole bits an utterance, far above any frame's gain): it catches gross arithmetic errors, not subtle ones. The tight reference for FRAMES stays `G(F_oracle)`, F_oracle = the 24 allowed (colour, shape) pairs that appear adjacent in that order (the structure the 6 exclusions leave), read from the same compressor.

## 4 · Marks, bars, nulls
- **PLANT-FOUND (a bar, every rule, both streams):** WEB-H, SENTENCE, MDL-GREEDY keep the planted frame; WEB-S keeps it at ≥ 9 of 10 seeds; and each such set's `G` > 0.
- **SHUFFLE-QUIET (a bar, every rule, ALPHA4):** `G(F)` ≤ the null's q95, or F is empty (printed).
- **GAIN(rule, ALPHA4) (the bar the toy is for):** `G(F) > q95` of its dealt null AND `G(F) > 0`; WEB-S is judged by the number of its ten seeds that pass (printed; «passes» needs ≥ 8 of 10, exact sign p = 0.055).
- **GATE FIRST:** if the PLANT fails for a rule, that rule's GAIN is NOT GRADABLE (the instrument cannot find a frame it was handed); if the SHUFFLE is not quiet for a rule, its GAIN reads NOT GRADABLE (it finds frames in noise). **GATE-CEIL** (§3): a `G` above `G_max + 20` on plain SCENE is an instrument error and the run STOPS. **PLANT-BEATS-NULL-2** (a gate on the NULL-2 reading only): on each PLANT stream the one-frame set {(zzq, xxv)} must have `G ≥` the q95 of its own NULL-2 (100 draws, §3) — a null that the planted frame (the maximal-PMI frame at its count) cannot beat is blind or too strong, and NULL-2's reading for that stream is NOT GRADABLE (printed; no bar depends on it). The planted frame's count (≈ 60 % of the plants in the train part) may have no real adjacent bigram in its bin (SCENE has none): the fallback bin is then counted and printed.
- **Readings (no bar):** per rule the size |F|, the share with a within-moment adjacent train occurrence, `G` in bits and per held-out word, NULL-1's mean / sd / q95 and the rule's z, **NULL-2's mean / sd / q95, z, fallbacks and CRITERION-MATTERS**; the rules' overlaps (Jaccard); on SCENE `G` beside `G_max` (both forms of §3) and `G(F_oracle)` and each rule's recall of F_oracle; **THE EYE'S READING (ALPHA4):** the cells' 40 distinct said frames, each with its says and its yes-count; for each rule, how many of the 40 it keeps, the pooled yes-rate of the says of the frames it KEEPS against those it does not (n printed), and the frames it keeps that the cells never said.
- **Predictions** (written before any run; the counts of §0 were read): **P-C1** [Likely] MDL-GREEDY's `G` is the largest (it optimises the TRAIN version of this very quantity). **P-C2** [Guessing] WEB and SENTENCE beat their dealt nulls on ALPHA4 (their pairs co-occur far above chance) but with `G` below MDL-GREEDY's, because they keep rarer pairs that cost more than they save. **P-C3** [Guessing] on SCENE no rule beats its null by much (the structure is the 6 exclusions): every `G` ≪ `G_max`. **P-C4** [Likely] the eye's reading splits the rules' frames: the game pairs («green box», «yellow key», «red box» …) are kept by MDL-GREEDY and are the ones the eye confirmed, while the function-word pairs it also keeps («of the», «to the») are not — compression and grounding point at different frames. **P-C5** [Guessing] SENTENCE keeps «the letters», «a big», «to the» (the most said, 0 confirmed) and a game pair or two. **P-C6, two guesses on NULL-2, both written before any run:** [architect's, Guessing] MDL-GREEDY's `G` sits near NULL-2's band on ALPHA4 (its gain is count-driven), and a rule clearly above NULL-2 has a criterion that matters; [mine, Guessing] the opposite for MDL — it picks the best-PMI bigram of each count from every candidate, a random adjacent bigram of the same count has a lower PMI, so MDL-GREEDY's `G` is above NULL-2's q95, and WEB and SENTENCE (which pick by recurrence, not by saving) sit nearer to it.
- **Refutations:** «a rule's frames shorten unseen text because the pairing is real» is refuted for a rule if its `G(F)` is inside its dealt null (NULL-1); «a rule's criterion picks better than a random adjacent pair of the same count» is refuted for a rule if its `G(F)` is inside NULL-2's band (a reading); P-C4 is refuted if the rule's kept frames have the same yes-rate as its dropped ones (within the sampling of 40 frames); «compression finds what the eye confirms» is refuted if the kept frames' pooled yes-rate is below the 86 / 526 = 0.163 base rate.

## 5 · Where can the mechanism fire (the adversarial walk)
1. **Adjacent occurrences.** A frame compresses only where its two words stand adjacent INSIDE a moment of the held-out part; the ALPHA4 stream has 36,078 + 3,148 + … words in multi-word moments (shelf 799 × 2 + 592 × 3 + 8,176 × 4 = 36,078; game 3,148), and the 35,294 maker words and 37,546 single-word shelf moments can host none. Every kept frame's held-out adjacent count is printed; a frame with zero is a frame that cost bits and saved none.
2. **A bar above its ceiling?** GAIN's bar is a percentile of the dealt null, so it has no absolute ceiling; the SCENE ceiling is now a GATE from the generator's own code (§3, END; loose by whole bits an utterance, so it catches gross errors only) and `G(F_oracle)` is the tight reference; the PLANT is the arithmetic proof that the compressor CAN save bits on a frame it is given, and PLANT-BEATS-NULL-2 the proof that NULL-2 can be beaten.
3. **Ablated systems on the marks' own items.** `∅` (G = 0) is the ablated compressor; NULL-1 is the ablated PAIRING (same sizes, same frequencies, chance partners — almost never adjacent); NULL-2 is the ablated SELECTION CRITERION (adjacent bigrams of the same count, picked at random); the SHUFFLE is the ablated STREAM.
4. **A frame that spans a moment** (the last word of one chunk and the first of the next): not parsed, by §1, and the web may propose it (dropped, counted).
5. **MDL-GREEDY overfits TRAIN by construction**; the HELD-OUT part is where it is graded. The model cost L(F) is paid per frame once, against the held-out text only: a frame needs enough held-out occurrences to repay `2 log₂ V ≈ 23` bits.
6. **The eye's reading is 40 frames, and the cells' frames came from the cells' OWN rule on a stream of five sources**: a reading, never a bar; the n is printed.
7. **Where NULL-2 can fire.** Its pool is the train's adjacent bigrams, the same pool MDL-GREEDY draws from (count ≥ 2 for MDL), matched on the count of each frame's OWN adjacent occurrence — so «it is frequent» is removed from the claim and only the choice among equally frequent adjacent pairs is left. A rule whose frames were never adjacent (SENTENCE's, the web's) is matched into count-1 bigrams, the weakest adjacent competitors, and the reading says so by printing the share of such frames; where a bin holds fewer candidates than the rule has frames the fallback is counted. NULL-2 can be beaten only by a pick that has HIGHER PMI at its count than a typical adjacent bigram — which is what PLANT-BEATS-NULL-2 checks, with a frame whose PMI is the maximum at its count.
8. **What a pass would NOT show.** That the organism should say frames by compression: the cells' mouth is judged by the EYE, and compression alone cannot know what the eye sees. The toy answers which selection rule gives pairs that compress unseen text beyond chance, and whether those are the pairs the eye later confirms.
