## 2 · Declared readings (decided, tested, said)

- **Answer row** = `{kind: "answer", by: "brain"|"organs", item, mark, form, answer, moment, seq, eye_seq, at, fix, hyps, detail}`. `seq` = the ASK row's seq; `eye_seq` = the canvas it was answered on (None for begin/end/why); `at` = the row the answer was MADE on (the eye row's for a held ask). `fix` = the canvas's located fixation cells, glance order; `hyps` = the eye's hypotheses' member lists into `fix` (None canvas-less). `answer` = `Brain.ask`'s return WHOLE (numpy → plain, `Infinity` kept, no key or list re-ordered) or the organs' answer; `detail` = the organs' diagnostics (cells per word, scores, the recall reason) or None for the brain.
- **Learn row** = `{kind: "brain", act: "learn", moment, seq (the eye row's), at, fix, hyps, …learn's return}` (the brain's own keys win if it returns `fix`/`hyps`); `act: "calibrate"` follows when `learn` says `calibrated`, carrying `summary()`. An eye row the brain hears without `scene`/`world_seed` → `act: "refused"` by name (never a crash loop, #230).
- **The brain's glance is the glance BEFORE the organism's `--blind coarse` strip** (`g_eye`): the strip rebinds `g` to a new dict, the brain's dict keeps `feats[len(fix)]`. Tested implicitly by `FakeBrain.learn`, which asserts the coarse glance is present. `--blind gaze` still changes the brain's glance (it is the eye's blind, shared).
- **The brain hears the TAPE's words** (captured before `--blind ear` clears `words_in_instant`): its own blind is `--blind brain`.
- **`begin` / `end` / `why` answered at once; `point` / `what` / `say` held** to their moment's eye row, answered in tape order BEFORE the organism lives that canvas; a canvas with held asks is never learned from by the brain.
- **A `BrainError` from `Brain.ask`** (a malformed ask) is journaled as `{kind: "refused", reason, raw: {refused}}`, never a crash; any other exception still crashes (the crash law).
- **`brain_status()`** = `summary()` + `asks_answered`, `asks_by`, `asks_pending`, `learn_rows`, `refused_rows`, `restored`; the twin (BRAIN declared and blinded, or asks answered by the organs) → `{brain: None, blind, …counts}`; every other mind → None. ## 3 · THE ORGANS' ROAD, form by form (read-only; asserted per answer)

- **point** → the eye's hypotheses (`brain.scene.eye.hypotheses` over `feats[:len(fix)]`); each scored by Σ over phrase words of max over the word's own cells (`genome.questions.word_cells` on the words ledger) of `Organism.edge_many("sight", member glances, cell)`; best → `thing` (`hyp`, `pos`, `fix`; raw `{point, none: False, none_i: False}`); every score ≤ 0 or no hypothesis → `none` (raw `{point: None, none: True, none_i: True}`); a phrase word with no cell → `unheard` (raw `{point: None, none: None, unheard}`); a tie → `marks.tie_rng(test_seed, item)` (the brain's own generator). Never `misuse` (the organs hold no word types).
- **what** → the pointer (genome/brain.py's `pointer_hypothesis`, my copy pinned equal on 400 random cases) → `Organism.recall_many("sight", member glances)` (ANSWER / ABSTAIN inside) → the answer cell's ONE name in the words ledger → `words` (raw `{emit: [w]}`); any abstain / a cell that is not one word → `unknown` (raw `{emit: []}`); no fixation in the box → `unseen` (raw `{emit: None, uncovered: True}`).
- **say** → as what: `phrase` (raw `{spoken: [w], reason: None, target, readback_point: None}`), else `declined` with the recall's reason or `not_one_word`, no fixation → `unseen` (raw `{spoken: None, reason: "uncovered", uncovered: True}`).
- **why** → `genome.questions.why` (ASK's own road): no cell born on the word alone and no FAST episode of it → `unknown`; else `because` with up to 8 of those episodes, earliest first (the organs keep no responsibility), each `{moment: tape_moment, scene: parsed from sc<ws>t<i>, pos: None, where: glance 0's window}`, `rule: {over, band: None}`; raw = the answer.
- **begin / end** → acknowledgements `{kind: "begin"|"end", set}`.
