## 1 · Claims I think wrong or unsupported

1. **§Q1 rank 1: «Discriminating learning runs at roughly (0.06 / 0.735)² ≈ 1/150 of the rate the common part gets.»** — WRONG by two orders of magnitude, right in direction [Certain]. The 0.06 is a whole-vector deviation (the mean distance of a state from the mean state, over 111–114 units); the 0.735 is a PER-UNIT magnitude. The ratio that governs an SGD head is over whole vectors: a correction on state h moves another state h′'s logit by h·h′, whose common part is ‖h̄‖² and whose letter part is ≈ E‖h − h̄‖². On B1.1's A1 final states (the NAME-ask road, both seeds): ‖h̄‖² = 66.9 / 64.2 and E‖h − h̄‖² = 0.0045 / 0.0047 → **1/14,855 and 1/13,569** (`probe_review.out` (1)). The same numbers from F11's own figures: 0.735 × √114 = 7.85, squared 61.6, against 0.060² = 0.0036 → 1/17,000. Why it matters beyond the arithmetic: at 1/150 a few hundred more examples would have rescued the raw head — A1-TEACH's 745 extra examples tested exactly that and read chance (F4); at 1/14,000 no realistic count could, which is what the record shows. For comparison the INPUT F_pool is conditioned at **1/8.8** (‖x̄‖² 0.898 against 0.102): the trunk's saturation manufactured the conditioning problem the input never had [Certain].
2. **§Q3: «0/156 answered at 97 % confidence (F3/F11)»** — SUPPORTED for B1.0, WRONG for B1.1 [Certain]. A1's own `raw.conf` at T_L: B1.0 seed 1 mean 0.995 (min 0.994, max 0.995), seed 2 0.994 — the CONST block's 78 corrections drove «a» to certainty; B1.1 seed 1 mean **0.397**, seed 2 **0.261** (`probe_review.out` (3)). On the corrected tape the collapse comes with LOW confidence — and the abstention band could not catch it either, because A1's training-ask confidences were lower still (means 0.08–0.19 by thirds, `read_b11.out`), so the p5 band sat under the test confidence. The sentence should say B1.0, and the lesson is sharper: a confidence read off a mis-conditioned head is meaningless at BOTH ends.
3. **§Q4 IMPRINT: «a new name's readout row is born from its first grounded example … never from zero»** — as a GENE, unsupported, and on the record it buys nothing [Certain for the offline reading]. On F13's road (one pass, A1's final states, both seeds): the standardised SGD reader with a zero row reads 81 % / 55 %; the same reader with the new row born from its first standardised example UNSCALED reads **51 % / 28–31 %** (the imprinted logit is ≈ ‖z‖² ≈ H = 112 on its own example, so the softmax saturates and every later correction fights it); as a UNIT-norm row it reads **79–84 % / 55 %** and scaled by 1/H **81 % / 55 %** — both identical to the zero row on unseen fonts (`probe_review.out` (2), `imprint-raw` / `imprint-unit` / `imprint-scaled`; the same on the INPUT: 60–62 % / 40 % unscaled, 88–89 % / 62–64 % unit, 87–89 % / 63–64 % scaled = the plain reader). Three scales, none buys anything. The principled form of «born from its first example» is the class MEAN of a prototype/LDA reader — where it is the whole rule, not an initialisation — and that reader reads 92–95 % / 67–68 % on the same states (item 5). Recommendation: drop A1-NORM-TEACH-IMPRINT as an arm; keep the idea as SLDA's mean.
4. **§Q1 rank 3 / §Q2: «the representation loses a little» (69 vs 73 offline)** — TRUE, and I had the opposite wrong. My research (rank 2) said the trunk costs ≈ 20 pp for online and nearest-mean readers (73 → 55; 64 → 44). Tonight's probe with the SAME one-pass readers on the state and on the input settles it against me [Certain]: on T_L, RLS reads the STATE at **69 % / 69 %** and the INPUT at **67 % / 65 %**; SLDA the state at **67 % / 68 %** and the input at **66 % / 64 %**; only the metric-free `sgd-std` prefers the input (63 % / 63 % against 55 % / 55 %) and only the cosine nearest-mean loses 20 pp. So the state keeps everything the input has for a covariance-aware reader, in a geometry whose variance sits in few directions — an isotropic reader fails on it, a whitened one does not. ## 3 · Where the seat and I AGREE — exactly, for CONCLUSION-R2

1. **The diagnosis.** Every network in B1 failed to learn letter names because its answer head — a zero-initialised linear classifier trained by plain SGD (lr 0.01) — read a RAW, near-saturated state whose common part (‖h̄‖² ≈ 64–67) dwarfs its letter part (E‖h − h̄‖² ≈ 0.005; ≈ 1/14,000). The state itself keeps the letters (a standardised linear reader: 96–97 % taught, 69–71 % unseen fonts, every variant, both seeds — F11, `probe_state.out`). One change — standardising the state before the head, nothing else — takes A1's own one-pass recipe from 4 % to 79–84 % (F13, both seeds). The world head's own letter sub-head fails identically (`probe_world_head.out`).
2. **What is NOT the cause:** truncated credit assignment (the exact-gradient twin fails the same), the FEEDBACK-only road (A1-TEACH = A1), sleep (A1-NO-SLEEP = A1), the number of examples (24 showings per letter suffice for a conditioned reader), curiosity (the tape is fixed), the CONST block (it chose WHICH name — the seat's correction 1c56bfc / d270ad2, credited).
3. **The mechanism of the one-name test answer:** every T_L ask starts from the same frozen state (`test_ask` never calls `fit_event`); the answer follows the start state, not the operand.
4. **The fix and its law:** every readout reads its inputs through per-unit running statistics (mean and variance; Welford), updated awake, FROZEN in sittings, persisted and hashed as learned state (the seat's HOMEOSTASIS = my A1-STD). Behind it the literature both of us name: LeCun et al. 1998 §4.3; Ba, Kiros & Hinton 2016.
5. **Online readers that learn from one pass on this CPU:** RLS on the centred state (63–69 % unseen fonts), streaming LDA / prototypes with a shared covariance (64–68 %), plain standardised SGD (54–63 %); cost sub-millisecond per event against A1's 430 ms as launched.
6. **The roles, corrected from CONCLUSION.md:** the rule library D is the composer and today the best namer (75 % T_L; 20/21 TWO_AFTER from 3 pairs; explains its rule); the cells are the fast store (one-shot, poor across fonts: 13–16 %); the network is the slow representation, read only through normalised heads; CONCLUSION had the network as the answering slow store and the library as a passenger — backwards.
7. **The first gate of every future brain arm** is F11 + F13 on its own states — a ceiling and a one-pass reader — before any architecture question; the B1 twin comparisons (GROWS, sleep, local/exact, attention, memory attention, MLC) are NOT GRADABLE on B1.0/B1.1: two raw-head chance readings each.
8. **The hybrids' SAME failure** must be fixed before they are judged; the record shows it is the NAME route (§1 item 8).
9. **Curiosity:** learning progress (Oudeyer, Kaplan & Hafner 2007) is the signal; asking the teacher when confidence is low is the awake form; replay prioritised by progress or error is the sleep form; both need the readout fixed first (a confidence off a mis-conditioned head is meaningless).
10. **Growth:** E48's laws kept — births on prediction error under a regenerating budget, Dohare's initialisation, no disuse decay; sleep should consolidate the ANSWERS too (both say it; both mark it untested).
11. **Sentences:** a relation over grounded things held by the library, grounded by recognisers, spoken only after read-back; never a next-token prediction; the six marks are the graders. We are at stage 1; no date.
12. **B1.2:** on B1.1's tapes and harness, both seeds, arms as one-difference switches on `ArmA1` (R46's pattern), twins SHUFFLED-NAME / SHUFFLED-RELATION / FORCED, B1.1's A1 record as the control that must still fail, the identity control (every switch off ≡ A1), no new bar, tonight-sized.
