One Life of the Genome

What is in the genome, in short. How the experiment runs, in plain steps. And his whole life drawn once, from the two inputs to the verdict.

1 · What is in the genome — 21 lines of text

The genome is a text file he can read and change. The machinery is fixed code that reads it and runs it; the genome itself never changes during a life. A gene the machinery does not know stops the organism from starting. Six families:

2 · The instructions — how the experiment runs

  1. Write the genome as the text file above. The machinery reads it. An unknown gene → it will not start.
  2. Make the world. Ten shapes (circle, square, triangle, cross, ring, bar, dot, star, arrow, wave), each with its name. Draw each shape 60 times with small jitter (position, size, tilt, noise). A moment is one picture and its word shown together.
  3. Gate G-a — measure before choosing. Pass every picture through the retina. Measure how alike two pictures of the same thing are, and how alike pictures of different things are. Set THETA_N between those two bands, THETA_M above the first. If the bands overlap, stop and report: the retina is too weak (the fix is a stronger fixed front, never a learned one).
  4. The toy first. A two-thing world (circle, bar) must answer Q1 perfectly. If it does not, the machinery is wrong, not the genome.
  5. The life. 600 moments in shuffled order. Moments 0–200: the areas grow. Moments 200–600: the areas wire together. Nobody writes a cell; the stream does.
  6. Arrival 2. Five new things (moon, house, tree, cup, key) for 300 more moments, under a fresh budget. He must keep the first ten.
  7. Ask five questions. Q1 what is this (a new picture) · Q2 show me a «word» · Q3 is this a «word»? · Q4 which of these two is a «word»? · Q5 a thing never shown → he must say «I do not know».
  8. Score outside him. A ledger the organism never reads knows which thing each cell was born on. He returns a cell; the ledger says whether it was right.
  9. Run the twins on the same road, each blind to one thing: words paired at random, growth frozen, wiring off, twenty random genomes, one planted made-up pair («zog»), one pair never shown.
  10. Read the nine marks. All must pass. The bars are written now, before any number is seen. A failed bar is a finding, never moved.
  11. Replay. The same genome and the same stream, run twice → the same organism, byte for byte.
  12. If it passes: rung 1 is his test — he drops a few pictures per word into /data/dev/genome/world/<word>/ and asks through a small door (ask what-is picture.png, ask show cat). Rung 2, only after that: a lineage — mutate the genome's numbers, select on held-out families, the random-genome control kept.
What "it works" means, in one sentence. Grown from the genome text alone, he names things he met with picture and word together at 0.80 or better on pictures he never saw, says «I do not know» on things never shown, and a second life from the same genome and stream is byte-identical.

4 · Inside one moment

This is the loop that runs 900 times in one life. The picture and the word arrive together; each passes a fixed front into its own area; each area either births a cell or picks five winners; from moment 200 the winners of the two areas are wired; housekeeping removes the wrong and the redundant.
